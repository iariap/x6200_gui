# Protocolo de escucha (futuro, requiere autorización; no ejecutado)

1. Build QA autorizada + radio en RX, fuente SSB débil con QRM y sin QRM, volumen fijo; sin TX/PTT/ATU.
2. Escucha ciega A/B/C (nativo, bypass, DSP actual) y candidatos D1/D2 **sólo si** el owner autoriza
   el cambio experimental en una build de prueba; orden aleatorizado, N≥10, misma fuente/segmento.
3. Criterios: inteligibilidad de palabras/frases, esfuerzo, fatiga, artefactos metálicos/bombeo,
   continuidad, latencia percibida; registrar comentarios y preferencia.
4. No introducir EQ/preset nuevo ni defaults; si no hay preferencia consistente, mantener DSP actual.
5. Evidencia acústica/grabaciones autorizadas; no se presenta como readback ni PASS de producción.
